> Tier：B（暫定；改變切句單位、意圖判定與送後端內容）
> 流程豁免：老師 2026-10-12「以後測試不用等我認可，就是 try」；提案學生確認沿用，會議報告
> 提案學生：吳佳杰　　版本：草稿 v0.1（2026-10-14）

## 1. 需求（GD 步驟 1，2026-10-14 提案學生確認）

- **要解決什麼問題**：一輪裡的多個問題合成一句，意圖判斷錯誤或漏掉問題，影響照護員收到的回答和轉督導。
  - 用 RODE 收音時 VAD 幾乎不切句（`external-mic` 第 10 節後的實測），一句長達 12～17 秒，例如：
    > 家屬今天下午會來探視想帶水果給阿公吃阿公有糖尿病香蕉跟葡萄可以吃嗎另外機構可以幫忙代購尿布跟溼紙巾嗎

    這一句含兩個問題，卻只判出一個意圖（規範詢問，信心 0.53）。
- **誰會用**：照護員（回答）、督導（轉督導的問題）、後端（收到問題與相關前文）。
- **不做會怎樣**：多個問題被漏答；會議提到的「每個人說話的 window 不一樣」沒有落實。
- **決定**：
  1. 問句一律**單獨切出**；判定方式為標點模型的「？」，加上依教育部用法整理的問句規則（第 4.2 節）。
  2. 陳述句**保留自己的意圖**（例如「他說頭有點暈」仍判為身體不適陳述）。
  3. 最後沒有接問句的陳述，**自成一個單位**（反映自己目前的狀況）。
  4. 前文可以**跨說話人**（長輩說「我肚子痛」，照護員問「可以吃止痛藥嗎」）。
  5. 逐字稿：前文放在一起（window），問句單獨列出，問句的意圖要看前文再判定。
  6. 送後端：window 內**與問題有關的陳述**加上問句，例如「阿公有糖尿病。香蕉跟葡萄可以吃嗎？」。
  7. 分兩階段：第一階段只改服務內部和送後端，畫面只做標示；第二階段再改畫面與匯出。**如果效果不好，改採論文的方式**（第 3.3 節）。

- 本設計的 window 是**語意上哪幾句一組**，和論文的 Adaptive Endpointing（arXiv 2303.13407，時間上要等多久才斷句）不同；後者已在 10/12 實作（`ENDPOINT_MODE=adaptive`），切句 F1 0.571，比固定門檻的 0.603 還差。

## 4. 設計

### 4.1 window 的定義

- 一輪內，依時間順序，從上一個問句之後（或輪的開頭）到這個問句為止的陳述，是這個問句的 **window**。
- 問句本身單獨一句；連續兩個問句時，後一個問句的 window 是空的。
- 最後一個問句之後的陳述，自成一個沒有問句的單位。
- 前文可以跨說話人。

例：

```
[window 1] 家屬今天下午會來探視／想帶水果給阿公吃／阿公有糖尿病
[問句 1]   香蕉跟葡萄可以吃嗎？
[window 2] （空）
[問句 2]   另外機構可以幫忙代購尿布跟溼紙巾嗎？
```

### 4.2 問句判定規則（Q-A、Q-B）

依據：教育部《重訂標點符號手冊》修訂版（問號：用於疑問句之後，包含懷疑、發問、反問；強烈的反詰疑問句用驚嘆號），與《國語辭典簡編本》「嗎」「呢」「吧」的釋義。另外參考語言學通行的四類問句。

| 規則 | 算問句 | 不算問句 |
|---|---|---|
| 句尾「嗎」 | 「可以補吃嗎」 | 「這個嗎，讓我再考慮」（停頓、提示下文；簡編本「嗎」義項二） |
| 「呢」 | 句中有疑問詞或正反結構時：「這件事要怎麼解決呢」 | 只有「呢」：「很痛苦呢」「等我回去煮飯呢」（加強、確定語氣；簡編本「呢」義項二） |
| 「吧」 | 不單獨作為問句依據（簡編本的五個義項都不是疑問） | 「教教我吧」「好吧」 |
| 正反問 | 「是不是落針了」「有沒有發燒」「可不可以」「要不要」 | — |
| 選擇問 | 「要先量血壓還是先洗澡」 | — |
| 疑問詞（誰、什麼、哪、怎麼、為什麼、幾點、多少、多久） | 「你最近怎麼越吃越少」「我等一下幾點可以拔尿管」 | 「他什麼都不吃」「我怎麼叫他都不理」「不知道……」 |
| 反問、表達情緒 | — | 「你懂什麼」（提案學生判定為表達情緒） |
| 要求、勸阻 | — | 「你不要一天到晚詛咒他出車禍好不好」（提案學生判定） |

- 反問和要求很難只靠規則分辨，第一版先依上表的例子處理，再用資料檢查誤判。
- 規則只用在**標點模型切出的每個小句**上；小句以「，。？！」為界。

### 4.3 服務中的流程（第一階段）

1. VAD 切出一段 → ASR 整段辨識一次（保留前後文，不先切音訊，避免 10/14 原型「阿公→打工」的錯字）。
2. 標點模型為這段文字加標點 → 依第 4.2 節找出問句小句。
3. 依問句位置把文字切成「陳述段」和「問句」，音訊位置用字數比例推算（沿用 `at()`）。
   - 陳述段：問句前面連續的陳述小句合成一句，不再細切（維持現在一句一句的粒度）。
4. 每一句照舊判定意圖（陳述保留自己的意圖）；問句改用第 3.2 節選出的方式判定。
5. 資料庫 `utterances` 新增 `is_question INTEGER`、`window_id INTEGER`（一輪內的 window 編號）；舊資料庫啟動時以 `ALTER TABLE` 補欄位。
6. 畫面（第一階段）：逐字稿的問句前面加上「❓」，同一個 window 的前文以相同的淺色底標示。

### 4.4 送後端

- 每個**需要回答的問句**（意圖屬於規範詢問／服務請求／身體不適陳述）各送一次 `query`：
  - `text`：window 內的相關陳述（意圖為「資訊告知或交接」或「身體不適陳述」）以「。」相接，再接問句；
  - 新增 `question_utterance_id`、`context_utterance_ids`。
- **與 10/13 一輪多意圖的關係**：原本是「同一意圖去重複後送一次」；改成**問句逐一送**，同一意圖的兩個問句會各自得到回答。沒有問句的陳述（例如「我肚子好痛」）仍依原方式，每個意圖送一次。
- **已知的落差**：依 (b) 的規則，第 4.1 節的例子會送出「家屬今天下午會來探視。想帶水果給阿公吃。阿公有糖尿病。香蕉跟葡萄可以吃嗎？」，比提案學生舉的例子「阿公有糖尿病。香蕉跟葡萄可以吃嗎？」多。先照 (b) 實作，實測後再決定是否加上「與問句的關聯」篩選。
- 串接說明第 2 節同步更新。

## 8. 第 0 階段結果（2026-10-14）

### 8.1 問句判定

依提案學生審閱，補上規則（2026-10-14）：
- 詢問意見「你／您＋覺得／認為／看／想＋呢」算問句。
- 口語爭吵、責備不算問句：「你＋懂／知道／管＋什麼」（「什麼」在結尾）、「不要／別／少／不准…＋好不好／行不行」。
- 「如果／要是…呢」、「幾＋量詞」算問句。
- 非疑問用法不算問句：「好幾、這幾、多…幾」「有什麼…就」。
- 間接問句不算問句：「問／看看／要看／知道／確認…」接疑問結構，且句尾沒有「嗎」。

| 方法 | tk01～04（21 問句） | care7ctx（113 問句／457 陳述） |
|---|---|---|
| **Q-A 標點＋規則（補規則後）** | 召回 100%，誤判 0 | 召回 96.5%，誤判 1.1% |
| Q-A（補規則前） | 95.2%，誤判 2 個 | 95.6%，2.8% |
| Q-B 只用規則 | 100%，誤判 1 個 | 95.6%，0.9% |
| Q-C 只用標點 | 76.2%，誤判 1 個 | 87.6%，0.4% |

- **限制**：規則是看 tk 和 care7ctx 的錯誤寫出來的，所以補規則後的數字偏樂觀。公平驗證要用另外寫的 30 句測試句（`endpoint_recordings/question_rule_testset.csv`），等提案學生審完標準答案再測。
- 10/14 文稿錄音的 8 個問句，人工檢查全部都有抓到。但 RODE 第 2 輪的第一個問句連同前面的陳述一起被切出來，因為標點模型沒有加逗號。**要判斷問句從哪裡開始**，這部分待實驗。

**盲測結果（用測試句之前的規則）**

| 方法 | 問句抓到 | 陳述誤判 |
|---|---|---|
| Q-A 標點＋規則 | 11/15 = 73.3% | 6/15 = 40.0% |

**未達成功標準**。這表示先前 tk、care7ctx 的好成績，有一部分是因為規則是依那兩份資料寫的。

**錯誤原因與修正**：
1. **標點模型的逗號把句型拆開**：「飯前吃，還是飯後吃」「有什麼不舒服，就按床頭的鈴」「去問護理站，有沒有多的手套」。
   - 修正：改成**整句判斷**（句號、問號、驚嘆號之間算一句）。
   - 判定為問句之後，如果句中前面的小句本身也是問句就分開（「你最近怎麼越吃越少，是不是又在痛」是兩個問句），再找出問句從哪個小句開始。
2. **標點模型把問號加錯位置**：「我怎麼勸？她都不肯吃藥」。
   - 修正：非疑問用法（怎麼…都、什麼…都、有什麼…就）跨問號檢查。
3. **規則漏洞**：
   - 「請問」裡的「問」被當成間接問句。修正：「請問」標記問句的起點，「請問」之後的整段都是問句，但「請問」不能單獨切出一個問句。
   - 「還是」只搭配「呢」。修正：「A 還是 B」本身就是選擇問；「還是很／一樣／沒／不／都」是副詞，不算。
   - 量詞清單補上「度、公斤、公分、公克、毫升」。
   - 新增句尾「了沒／過沒」。
   - 「難道」列為反問（情緒表達）。
   - 爭吵「…懂什麼」不限主詞，但「想知道什麼」「要知道什麼」除外。

**修正後**

| 30 句測試句 | 15/15 | 0/15 |

- **仍待處理**：RODE 第 2 輪「…阿公有糖尿病香蕉跟葡萄可以吃嗎」，標點模型在問句前面沒有加任何標點，所以問句起點的判斷無從作用，切出來的問句仍包含前面的陳述。

## 9. 第一階段實作（2026-10-14，提案學生確認開始）

### 9.1 依停頓補逗號（提案學生 2026-10-14 指示）

- **問題**：文字全部連在一起時，標點模型沒有加任何標點，問句起點的判斷無從作用（RODE 第 2 輪）。
- **做法**：提案學生指示「讓麥克風偵測停頓或換氣，標出逗號」。
  - Paraformer 有輸出每個字的開始時間；字與字的間隔 ≥ 0.5 秒時，在中間補「，」（`questions.insert_pause_commas`）。
  - 一般字間隔約 0.25 秒；RODE 第 2 輪的句間間隔為 0.56～1.04 秒。
  - 先補逗號再轉繁體，逗號不受轉換影響；字數和時間數不一致時（例如含英文子詞）不補。
  - 換氣聲也是兩個字之間的空檔，所以同樣會被補上逗號，不另外偵測換氣聲。
- **合併規則**：標點模型的標點優先，模型沒有加標點的停頓處才補「，」。
- **效果**：同一段 RODE 文字補上停頓逗號後切成：
  ```
  家屬今天下午會來探視，想帶水果給阿公吃，阿公有糖尿病
  ❓ 香香蕉跟葡萄可以吃嗎？
  ❓ 另外，機構可以幫忙代購尿布跟溼紙巾嗎？
  ```

### 9.5 問句起點改為整句、陳述依句號分開（2026-10-14，提案學生確認試做）

**問題**（N0 手機實測，`n0-intent-model-script.md`）：外接麥克風模式下 VAD 沒有切句（見 `external-mic` 第 11 節），整輪一段，問句被切短，信心很低：
- 「不去，附件嗎？」確認或同意 0.43，應為「住民可以自己決定不去復健嗎」；
- 「加在粥裡面嗎？」規範詢問 0.41，應為「長輩不肯吃藥的時候可以把藥磨碎加在粥裡嗎」。

陳述也被併成一句，只判出一個意圖。例如「膝蓋很痠＋麻煩聯絡復健師」只判成服務請求。

**提案學生問：要不要把前文加進問句？** 以 N0（照護員）比較：

| 問句 | 被切短 | 完整問句 | 整段（前文＋問句） |
|---|---|---|---|
| 住民可以自己決定不去復健嗎 | 確認或同意 0.43 | **規範詢問 0.95** | 服務請求 0.87 |
| 長輩不肯吃藥…加在粥裡嗎 | 規範詢問 0.41 | 服務請求 0.77 | 拒絕或抗拒 0.39 |
| 可以幫我把一條乾淨的毛巾拿過來嗎 | 服務請求 0.94 | **服務請求 0.96** | 服務請求 0.95 |

加入前文反而容易被帶偏，與第 8.2 節及 Rolling window 的結論一致。所以**不加前文，改為把問句切完整**。

**停頓長度**（ASR 每個字的時間）：句間 0.84～0.94 秒，句中多為 0.5～0.72 秒（猶豫時可達 0.9～1.4 秒）。

**修正**：
1. ASR 字間隔 ≥ 0.85 秒補「。」（句子結束），0.5～0.85 秒補「，」；長停頓的「。」蓋過標點模型的逗號。
2. **問句起點改為上一個句號之後的整句**（`QUESTION_START = "whole"`），不再挑「最短、仍是問句」的一段；同一句中有多個問句時仍分開。
3. **陳述遇到句號、驚嘆號就分開**，各自判定意圖。
4. 句子明顯沒說完（結尾是「把…、一條、幫我、的時候、的話、要、可以、跟、因為、如果」等）時，句號改為逗號、併入下一句。例如「可以幫我把一條。乾淨的毛巾拿過來嗎」→「可以幫我把一條，乾淨的毛巾拿過來嗎？」。

**結果**：

- 以 N0 文稿錄音的整輪音訊模擬最壞情況（整輪當成一段），14 句意圖：錄音當時 8/14，修正後 **11/14**。
  - 改對：膝蓋很痠（身體不適）、住民可以自己決定不去復健嗎（規範詢問）、精神很好喔（閒聊）、頭很暈想吐（身體不適）。
  - 仍錯：「請幫我把三樓的輪椅送去維修」→ 資訊告知；「他剛剛把藥吐掉了說不要吃」→ 拒絕或抗拒；「長輩不肯吃藥…加在粥裡嗎」→ 服務請求。
- 其他資料不退步：tk 21/21、誤判 0；care7ctx 110/113、誤判 4/457；30 句全對。
- **代價**：
  - 沒有長停頓時，問句前的陳述會併入問句（例如「中午只喝了幾口湯，發燒的時候，可以讓他洗頭嗎」）；
  - 猶豫造成的長停頓會把一句切成兩句（「由陳。小陳。接手。」，只有 1～2 個字的片段會併到下一段）。

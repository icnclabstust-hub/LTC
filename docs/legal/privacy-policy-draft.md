## 二、蒐集的資料與用途

| 資料 | 怎麼取得 | 用途 |
|---|---|---|
| LINE 使用者識別碼（userId）、LINE 顯示名稱 | 您加入官方帳號、登入 LINE 網頁時由 LINE 提供 | 辨識身分、回覆訊息、切換選單 |
| 姓名、身分（居服員或督導）、匿名代號（例如 CG-0012） | 機構管理員建立帳號時輸入，或系統自動產生 | 綁定帳號、權限控管；送交問答系統時只使用匿名代號 |
| 您輸入的問題文字 | LINE 聊天室、LINE 網頁打字提問 | 查詢知識庫並回答；無法回答時轉給督導 |
| 錄音與逐字稿 | 您在 LINE 網頁開啟錄音模式，且在場者已同意錄音 | 語音轉文字後提問；督導確認逐字稿 |
| 督導的回覆 | 督導在督導頁面輸入 | 回覆您的問題 |
| 服務紀錄（時間、回覆是否成功、拒答原因） | 系統自動產生 | 統計拒答原因、改善知識庫與服務品質 |

**請勿輸入個案或家屬的真實姓名、身分證字號、電話、地址或房號，請一律使用代稱。** 系統會在處理前自動遮罩身分證字號與電話號碼，但無法辨識所有個人資料。

您的提問可能涉及個案的健康狀況，屬於《個人資料保護法》第 6 條的特種個人資料。我們只會在提供本服務及【學術研究】的必要範圍內處理，並採取第五節的保護措施。

## 三、資料存放與處理方式

- 問答使用的語言模型、語音辨識模型都在【實驗室／機構】的電腦上執行，**不會把您的資料送到外部的 AI 雲端服務**。
- 資料存放在【實驗室／機構】的電腦（【地點】）。
- LINE 訊息會經過 LY Corporation（LINE）的伺服器傳送，適用 LINE 的隱私權政策：https://line.me/zh-hant/terms/policy/
- 除了以下情形，我們不會把您的個人資料提供給第三方：
  1. 您描述緊急狀況時，系統會通知居服督導；
  2. 依法律規定必須提供，例如疑似受虐依法通報。

## 四、保存期限

| 資料 | 保存期限 |
|---|---|
| 聊天室與網頁提問、小照的回答（前端） | 24 小時 |
| 轉給督導的問題 | 督導回覆前持續保存；回覆後 1 天 |
| 錄音音檔（供督導回聽） | 督導確認後立即刪除；最長 7 天 |
| 未經督導確認的逐字稿 | 7 天 |
| 督導確認過的逐字稿（人名已換成代號，供知識庫使用） | 被知識庫取走後 30 天；最長 90 天 |
| 問答系統的提問與回答紀錄（已遮罩身分證字號與電話） | 【待訂，例如 1 年；試用結束後刪除或去識別化】 |
| 帳號資料 | 帳號停用後【待訂】 |

保存期限屆滿後，系統會自動刪除。
